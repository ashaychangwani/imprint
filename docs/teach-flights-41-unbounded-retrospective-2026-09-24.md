# Flights41 unbounded teach retrospective

Flights41 started fresh on `20bfc88` with the combined September 4 Google Flights recording and the four requested operation groups. It ran for 143.8 minutes, published location lookup and one-way search, and ended with two ready and three not-ready capabilities. Its isolated home, journal, raw responses, native agent history, live checks, and independent reviews remain at `~/.imprint/experiments/reteach-systemic-2026-09-21/flights-41-unbounded/`. It did not reach the independent completion audit and does not count toward repeatability acceptance.

The previous final-sweep fix worked. The first location parser omitted four nested San Sebastián choices; the independent reviewer rejected it, the master received the failure, and a retained compiler repaired the parser. The revised location tool passed the paired recorded/live review and published. One-way search initially received only an application error from direct POST. Research changed execution to a browser-owned navigation that captured the page-issued shopping API response. Its live-only parser review passed because the recording did not capture response 206, and the tool published.

Multi-city search also changed to page-issued API capture and produced 22 live choices. Its first recorded parser duplicated choices and missed an itinerary token. The next revision had the correct 19 recorded choices but extracted one fare as 233 USD instead of the frozen 238 USD. A further parser revision reached review, but the reviewer spent six bounded inspections navigating the deeply nested recorded response; two projections failed on unexpected shapes. It could establish representative facts but not complete recorded membership before its inspection allowance ended, so it honestly returned unverified. This was an evidence-inspection limit, not proof that the revised parser was correct.

One-way booking executed both its own live case and a fresh search-to-booking chain. The chain selected the producer's first itinerary, Alaska AS 1307, while the recorded booking case selected Southwest WN 367. The reviewer correctly rejected comparability. The master did not revise the chain edge and the same plan and failure state recurred. The date-grid operation was also unresolved: an earlier 49-cell parameterized response did not establish the later no-input contract, and that exact contract returned RPC application error [13] on four backends. The run ended at the repeated-state safeguard rather than looping indefinitely. Disk, sleep, and internet disconnection were not the terminal cause.

The immediate general correction raises each independent review phase from six to twelve bounded evidence inspections. This does not change citations, comparability, or parser-fidelity requirements; it lets reviewers recover from incorrect structural projections of large responses. A regression completes a review after eight inspections. Focused tests, the full 2,067-test suite, lint, and type checking passed. Booking comparability and date-grid execution remain separate agent-level problems to observe in the next fresh run; neither is waived.
