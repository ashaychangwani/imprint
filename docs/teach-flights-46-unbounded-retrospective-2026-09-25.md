# Flights46: recorded chain cases could not be selected

Flights46 started fresh on `4f9281c` and ran unbounded for 267.7 minutes. We stopped it cleanly before changing the runtime; its recordings, agent turns, responses, and failed checks remain under `~/.imprint/experiments/reteach-systemic-2026-09-21/flights-46-unbounded/`. The run ended with four usable MVPs—location lookup, one-way search, one-way booking options, and round-trip search—and three unfinished tools. No independent audit ran, so this is not a successful teach.

The repeated lookup-to-details chain was the clearest runtime blocker. The producer's default live case queried New York, while the consumer's selected recorded case was an airport lookup. The chain made a successful fresh HTTP call, but the evidence reviewer correctly marked it unverified because those calls were not comparable. The master asked the details compiler to repair it several times, yet the chain runner always chose the producer's first live case. A compiler cannot change that choice. The general fix lets the master or focused planner name the producer and consumer live cases on an edge, executes the producer case freshly, and keeps its receipt separate from the default proof. No site-specific rule chooses a case.

Other unfinished work was agent/artifact repair rather than this runtime mismatch. The date-grid compiler fixed a pre-click network wait, then its live case shifted still-valid recorded dates by seven days without a freshness reason. Multi-city search first lost the best/other boundary, then hardcoded a 3/16 split even though the fresh response had a 5/13 split. The location-details parser omitted recorded airport/city boolean and null fields. Those findings were returned to retained agents; this interruption did not erase their evidence. The successful one-way search-to-booking chain used fresh search output.

The trace reports 35,798,190 input tokens, including 32,796,672 cache reads, 283,663 output tokens, and zero reported cache writes. Fifteen analysis spans lack usage. The reported base API-equivalent cost is therefore only a $30.7980008 lower bound, not a complete bill. Disk remained near 2 GiB free and the caffeinated process stayed active; neither space nor sleep caused this interruption.

The chain-case fix passed its selected-case end-to-end regression, receipt isolation regression, plan validation checks, lint, type checking, and the full 2,071-test suite. Flights47 must start in a fresh home on the changed runtime; Flights46 is never resumed.
