# Flights40 unbounded teach retrospective

Flights40 started fresh on `bd755b8` with the combined September 4 Google Flights recording and the four requested operation groups. It ran for 101.7 minutes and exited with zero ready and nine not-ready tools. The run never reached independent completion audit. Its isolated home and failed evidence remain at `~/.imprint/experiments/reteach-systemic-2026-09-21/flights-40-unbounded/`; 39 research response records and three live-check files were retained.

Research proved nine API paths. The master planned separate location lookup, one-way, round-trip and multi-city search, round-trip date grid, return options, next-leg options, and booking tools. Multi-city booking was factually blocked in research and omitted from the plan. Location lookup produced a successful live response. One-way search's first CDP request timed out after receiving the endpoint response headers but before the body finished. Round-trip search completed its live request and began independent recording review. These outcomes did not themselves terminate the teach.

The location parser's independent review found a real omission: the recorded San Sebastián suggestion had six nearby components, while the parser returned only Bilbao Airport and San Sebastian Airport. The reviewer rejected both paired cases. The controller correctly removed that result from its in-memory approved-live map, while its mechanically passed live receipt remained in the journal. At the end of the compile pass, the final sweep treated the receipt alone as grounds to publish and threw `MVP tool "lookup_flight_locations" has no retained live result`. That exception bypassed the normal master repair path and masked the useful semantic finding. The live response was retained; the error message was misleading.

The independent round-trip reviewer also reached a five-minute expectations-phase deadline while inspecting nested recorded frames. The `bd755b8` retry fix worked: it recorded one retry and continued the same retained reviewer conversation. This was not the terminal failure. Disk and process sleep were not the cause of this run's failure.

The general correction skips final-sweep approval for tools that already have a recorded failure in this pass. The original semantic finding then reaches the master, which can recall and repair the parser. A regression now gives one tool two selected live cases and rejects the second case despite a passed transport receipt; it verifies that the retained compiler receives the failure and a fresh build can pass. Invalid proof remains rejected. Focused controller tests, the full 2,066-test suite, lint, and type checking passed. The correction requires a new isolated teach rather than resuming Flights40.

Token, cache, and cost accounting for this failed attempt is pending trace recovery. No result from this run counts toward repeatability acceptance.
